## ¿Qué es un notebook?

Un *notebook* es un documento que mezcla **texto** (como este) y **código** que se puede ejecutar. Google Colab ejecuta el código en un computador de Google: solo se necesita un navegador y una cuenta de Google.

**Antes de empezar:** Archivo › *Guardar una copia en Drive*. Así los cambios quedan en su cuenta y no se pierden.

## Ejecutar una celda

Haga clic en la celda de abajo y presione **Shift + Enter** (o el botón ▶).

```python
print("¡Hola, Química Industrial!")
```

```text
¡Hola, Química Industrial!
```

Python también funciona como calculadora. La masa molar del agua:

```python
2 * 1.008 + 15.999
```

```text
18.015
```

## Instalar bibliotecas

Las herramientas de química (RDKit, PySCF) no vienen en Colab. Se instalan **en la nube** con `pip`. El signo `!` indica un comando del sistema. Cada vez que Colab se reinicia hay que volver a ejecutar esta celda.

```python
!pip install -q rdkit
import rdkit
print("RDKit versión", rdkit.__version__)
```

## Buenas prácticas
